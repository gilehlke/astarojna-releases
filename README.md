# Astarojna — Releases

Instaladores oficiais e metadados de auto-update do **Ostorozhno** (telemetria para o
War Thunder), do estúdio **Astarojna**.

- Baixe a versão mais recente em **[Releases](../../releases/latest)**.
- O app usa o `latest.json` deste repositório para auto-update (verificação por
  assinatura **minisign**).
- O código-fonte é proprietário — este repositório hospeda **apenas** os binários e os
  metadados de atualização.

🌐 https://astarojna.com
